本资料依据同济六版线性代数编写，用于RAG向量知识库，包含全部章节定义、定理、性质、公式、典型例题。

第1章 行列式
1.1 二阶与三阶行列式
定义1 二阶行列式：
|a11 a12|
|a21 a22| = a11a22 - a12a21
二元线性方程组
a11x1+a12x2=b1
a21x1+a22x2=b2
当系数行列式D≠0时，解为 x1=D1/D，x2=D2/D。D1是D第1列替换为常数项，D2是D第2列替换为常数项。

三阶行列式
|a11 a12 a13|
|a21 a22 a23|
|a31 a32 a33|
对角线法则计算。主对角线方向三项取正，副对角线方向三项取负。

1.2 全排列和对换
n个不同元素排成一列，称为全排列。全排列总数 Pn = n!。
逆序数：排列中前面数字大于后面数字的对数。
逆序数为奇数：奇排列；逆序数偶数：偶排列。
定理1 一次对换改变排列奇偶性。

1.3 n阶行列式定义
n阶行列式
D = Σ (-1)^t a1p1 a2p2 ... anpn
t为排列p1p2…pn的逆序数。
上三角行列式：主对角线下方元素全为0，值等于主对角线元素乘积。
下三角行列式同理。对角行列式等于对角线元素乘积。

1.4 行列式性质
性质1 行列式转置后值不变 D^T = D。
性质2 交换行列式两行（列），行列式变号。推论：两行（列）相同，行列式等于0。
性质3 行列式某一行（列）所有元素同乘k，等于行列式乘以k。推论：某两行成比例，行列式为0。
性质4 行列式某一行（列）元素都是两数之和，可以拆成两个行列式相加。
性质5 把行列式某一行（列）k倍加到另一行（列），行列式值不变。

1.5 行列式按行（列）展开
余子式Mij：划去第i行第j列，剩余n-1阶行列式。
代数余子式 Aij = (-1)^(i+j) Mij。
定理2（展开定理）n阶行列式等于它任意一行（列）各元素与其对应代数余子式乘积之和：
D = ai1Ai1 + ai2Ai2 + ... + ainAin
推论：行列式某一行元素与另一行对应代数余子式乘积之和等于0。

1.6 克拉默法则
n元线性方程组Ax=b，系数行列式D=|A|。
若D≠0，则方程组有唯一解 xi = Di/D，i=1,2,...,n。Di是D第i列替换为常数项b。
推论1 齐次线性方程组Ax=0，D≠0，则只有零解。
推论2 齐次方程组Ax=0有非零解 ⇔ D=0。

第2章 矩阵及其运算
2.1 矩阵
m×n矩阵：m行n列数表。记作 A=(aij)m×n。
方阵：m=n；行矩阵、列矩阵；零矩阵O；单位矩阵E（主对角线为1其余0）；对角矩阵。
同型矩阵：行数、列数全部相等。矩阵相等：同型且对应元素全部相等。

2.2 矩阵运算
矩阵加法：同型矩阵，对应元素相加。A+B=B+A；(A+B)+C=A+(B+C)。
数乘矩阵：kA，每个元素乘以k。k(A+B)=kA+kB；(k+l)A=kA+lA。
矩阵乘法：A是m×s，B是s×n，C=AB为m×n矩阵。Cij = Σ_{k=1}^s aik bkj。
矩阵乘法性质：
1. 不满足交换律 AB≠BA；
2. 不满足消去律，AB=O不能推出A=O或B=O；
结合律：(AB)C = A(BC)；分配律 A(B+C)=AB+AC；k(AB)=(kA)B=A(kB)。
方阵幂：A^k，k个A相乘。A^m A^n = A^{m+n}, (A^m)^n=A^{mn}。

转置矩阵 A^T：A的行变列，列变行。
转置性质：
(A^T)^T = A
(A+B)^T = A^T+B^T
(kA)^T = kA^T
(AB)^T = B^T A^T
对称矩阵：A^T=A；反对称矩阵 A^T=-A。

方阵行列式：方阵A对应的行列式记作|A|或detA。
|A^T|=|A|；|kA|=k^n |A|；|AB|=|A||B|。

2.3 逆矩阵
定义：n阶方阵A，若存在方阵B，使得 AB=BA=E，则A可逆，B是A的逆矩阵，记作A⁻¹。
定理1 A可逆 ⇔ |A|≠0。|A|≠0称为非奇异矩阵；|A|=0奇异矩阵。
伴随矩阵A*：A*=(Aji)，Aji是aij的代数余子式。
公式 AA* = A*A = |A|E。
A⁻¹ = (1/|A|) A*。

逆矩阵性质：
(A⁻¹)⁻¹ = A
(kA)⁻¹ = (1/k) A⁻¹ (k≠0)
(AB)⁻¹ = B⁻¹ A⁻¹
(A^T)⁻¹ = (A⁻¹)^T

2.4 矩阵分块法
分块矩阵，把大矩阵拆成子块。分块矩阵加法、数乘、乘法规则。
分块对角矩阵：
A=diag(A1,A2,...,As)，|A|=|A1||A2|...|As|
A可逆 ⇔ 每个Ai可逆，A⁻¹=diag(A1⁻¹,A2⁻¹,...,As⁻¹)

第3章 矩阵的初等变换与线性方程组
3.1 矩阵初等变换
三种初等行变换：
1. ri ↔ rj，交换两行；
2. ri × k，某一行乘非零常数k；
3. ri + krj，第j行k倍加到第i行。
初等列变换同理。初等变换不改变矩阵的秩。
矩阵等价：A经过有限次初等变换得到B，A~B。等价性质：自反、对称、传递。

初等矩阵：单位矩阵E做一次初等变换得到的矩阵。
定理：左乘初等矩阵，对应做行变换；右乘初等矩阵，对应做列变换。
方阵A可逆 ⇔ A可表示为若干初等矩阵乘积。

3.2 矩阵的秩
定义：矩阵A中最高阶非零子式的阶数，称为矩阵A的秩，记作r(A)。
规定零矩阵r(O)=0。
性质：
1. r(A_{m×n}) ≤ min(m,n)
2. r(A^T)=r(A)
3. 若A~B，则r(A)=r(B)
4. max{r(A),r(B)} ≤ r(A|B) ≤ r(A)+r(B)
5. r(A+B) ≤ r(A)+r(B)
6. r(AB) ≤ min{r(A),r(B)}
7. A_{m×n}, B_{n×s}, AB=O ⇒ r(A)+r(B) ≤ n

求秩方法：初等行变换化为行阶梯形，非零行的行数等于矩阵的秩。

3.3 线性方程组解的判定
线性方程组 Ax=b，增广矩阵$\overline{A}=(A|b)$。
1. r(A) < r($\overline{A}$)：无解
2. r(A)=r($\overline{A}$)=n：唯一解
3. r(A)=r($\overline{A}$)<n：无穷多解，自由未知量数目 n-r(A)

齐次方程组 Ax=0，一定存在零解。
Ax=0有非零解 ⇔ r(A)<n。

求解步骤：
1. 写出增广矩阵；
2. 初等行变换化为行最简形；
3. 判断解的情况；
4. 写出对应的方程组，确定自由未知量；
5. 写出通解。

第4章 向量组的线性相关性
4.1 向量组
n维列向量 α=(a1,a2,...,an)^T；行向量α^T。向量加法、数乘。
向量组：若干同维向量构成集合。矩阵的列向量组、行向量组。

4.2 线性组合与线性表示
定义：向量β，如果存在数k1,k2,...,km，β=k1α1+k2α2+...+kmαm，则β可由向量组α1,...,αm线性表示。
β可由α1…αm线性表示 ⇔ r(α1,…,αm)=r(α1,…,αm,β)。
向量组B可以由向量组A线性表示：B中每个向量都可以由A线性表示。
向量组等价：A、B互相线性表示。等价具有自反、对称、传递性。

4.3 线性相关与线性无关
向量组α1,…,αm，若存在不全为0的数k1,…,km，k1α1+…+kmαm=0，则向量组线性相关。
仅当所有ki=0等式成立，则线性无关。
定理：向量组线性相关 ⇔ 向量组中至少一个向量可由其余向量线性表示。

判定结论：
1. m个n维向量，m>n，向量组必线性相关。
2. 部分组相关，则整体相关；整体无关，则部分无关。
3. 向量组无关，增加维数仍然无关；向量组相关，减少维数仍然相关。

4.4 向量组的秩
极大线性无关组：向量组T的一个部分组A，满足：A线性无关；T任意向量都可由A线性表示。
向量组的秩：极大无关组所含向量个数。矩阵的秩等于矩阵列向量组的秩，等于行向量组的秩。
定理：向量组B可由A线性表示，则 r(B) ≤ r(A)。

4.5 向量空间
向量空间V：n维向量非空集合，对向量加法、数乘封闭。
子空间：V的子集，仍然对加法数乘封闭。
基：V中的极大无关组；维数：基所含向量个数。
向量在基下坐标：设α1,…,αr是V一组基，α=x1α1+…+xrαr，则(x1,…xr)为α在该基下坐标。
基变换与坐标变换公式。

4.6 线性方程组解的结构
齐次方程组Ax=0，解集S，S是向量空间，称为解空间。
基础解系：解空间S的一组基。若r(A)=r，则基础解系含有 n-r 个线性无关解向量。
齐次通解：基础解系向量的线性组合。

非齐次方程组Ax=b，设η*是Ax=b一个特解。对应齐次方程组Ax=0的通解为ξ。则Ax=b通解：η = η* + ξ。
非齐次任意两个解之差，是对应齐次方程组的解。

第5章 相似矩阵及二次型
5.1 向量内积
向量内积 [x,y] = x1y1+x2y2+…+xnyn。
性质：[x,y]=[y,x]；[λx,y]=λ[x,y]；[x+y,z]=[x,z]+[y,z]；[x,x]≥0。
向量范数 ||x|| = sqrt([x,x])。单位向量：||x||=1。向量单位化：x/||x||。
正交向量：[x,y]=0。零向量和任何向量正交。
正交向量组：向量组两两正交。正交向量组一定线性无关。
施密特正交化：把线性无关向量组转为正交向量组。
正交矩阵：A^T A = E。A正交 ⇔ A^T=A⁻¹。正交矩阵行/列向量组是标准正交向量组。

5.2 特征值与特征向量
A为n阶方阵，若存在数λ和非零向量ξ，Aξ = λξ。λ：A特征值；ξ：λ对应的特征向量。
特征方程：|λE - A| =0；特征多项式 f(λ)=|λE-A|。
设A特征值λ1,λ2,…,λn
1. λ1+λ2+…+λn = tr(A) 迹，主对角线元素之和
2. λ1λ2…λn = |A|
若λ是A特征值，则λ^k是A^k特征值；若A可逆，则λ⁻¹是A⁻¹特征值。
不同特征值对应的特征向量线性无关。

5.3 相似矩阵
A,B n阶方阵，存在可逆矩阵P，P⁻¹AP=B，则A与B相似。
相似矩阵特征多项式相同，特征值相同，行列式相同，迹相同，秩相同。
定理：n阶方阵A可对角化（相似于对角阵）⇔ A有n个线性无关特征向量。
推论：A有n个互不相同特征值，则A一定可以对角化。

5.4 实对称矩阵的对角化
实对称矩阵A：A^T=A。
性质：
1. 实对称矩阵特征值都是实数；
2. 不同特征值对应的特征向量相互正交；
3. 实对称矩阵一定可以正交对角化，存在正交矩阵P，P^TAP = P⁻¹AP = Λ，Λ为对角矩阵，对角元是特征值。

5.5 二次型及其标准型
n元二次型 f = ΣΣ aij xi xj，aij=aji。写成矩阵形式 f = X^T A X，A为实对称矩阵。
二次型的秩：r(A)。
可逆线性变换 X=CY，把二次型化为标准形：f = k1y1² +k2y2²+…+knyn²。
正交变换法：X=PY，P正交矩阵，将二次型化为标准形，系数就是A的特征值。

5.6 用配方法化二次型成标准形
配方法：逐步消去交叉项，化为只含平方项的标准型。

5.7 正定二次型
惯性定理：二次型经过可逆线性变换，正惯性指数p、负惯性指数q不变，r=p+q。
正定二次型：∀非零向量X，f=X^TAX>0。A称为正定矩阵。
判定条件：
1. 正惯性指数 p=n；
2. A所有特征值 >0；
3. A各阶顺序主子式全部大于0（霍尔维茨定理）。

负定二次型：所有顺序主子式奇数阶<0，偶数阶>0。

第6章 线性空间与线性变换（选学，同济六版）
6.1 线性空间定义与性质
线性空间：集合V，数域，定义加法和数乘，满足8条运算公理。
子空间，零元、负元唯一性。

6.2 维数，基，坐标
基、维数、坐标定义，和第4章向量空间一致。

6.3 基变换与坐标变换
基变换公式，过渡矩阵，坐标变换公式。

6.4 线性变换
线性变换T：V→V，满足 T(α+β)=Tα+Tβ；T(kα)=kTα。
线性变换的矩阵：选定一组基，线性变换对应方阵A。T(α)在基下坐标=A乘以α坐标。
线性变换在不同基下矩阵相似。

典型例题
例1 计算3阶行列式
D=
|1 2 3|
|4 5 6|
|7 8 9|
解：r2-r1, r3-r2，得到两行成比例，D=0。

例2 A是3阶方阵，|A|=3，求|2A*|。
解：|A*|=|A|^(3-1)=9；|2A*|=2^3 * |A*|=8*9=72。

例3 已知A=[[1,2],[3,4]]，求A逆矩阵。
解：|A|=4-6=-2。A*=[[4,-2],[-3,1]]。A⁻¹ = -1/2 [[4,-2],[-3,1]]。

例4 方程组
x1+2x2-x3=1
2x1+4x2+x3=5
有无穷多解，求通解。
增广矩阵初等行变换，r(A)=r(A拔)=2<3，自由未知量x2。求出基础解系与特解，写出向量形式通解。

例5 矩阵A=[[3,-1],[-1,3]]，求特征值、特征向量，正交对角化。
特征方程 |λE-A|=0，λ1=2,λ2=4。求出对应特征向量，单位化构造正交矩阵P。

例6 判断二次型 f=x1²+2x2²+3x3²+2x1x2 是否正定。
写出A，计算各阶顺序主子式，全部大于0，则正定。
